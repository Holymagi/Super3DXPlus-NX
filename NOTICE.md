# Notice & Attributions

**Super3DX+ NX** is an unofficial Nintendo Switch homebrew port derived from **Super3DX+** and **Re3DX+**.

## Project Credits

- **Super3DX+ NX (Nintendo Switch Port):** Holymagi (2026) — Switch platform layer (`platform/switch`), `setup-switch.bat` build pipeline, physics build fixes, and Switch networking/NRO packaging.
- **Super3DX+ (Upstream):** smolderyguest and contributors — core engine enhancements, game mode restorations, graphics/audio fixes, and build tooling.
- **Re3DX+ (Original Reimplementation):** Original Re3DX+ authors and contributors.

## Third-Party Libraries & Toolchains

This port relies on the following open-source libraries and toolchains (each subject to its respective license):

- **devkitPro / devkitA64 & libnx** — Nintendo Switch homebrew toolchain and system library
- **SDL2 (`switch-sdl2`)** — Windowing, input, and audio abstraction
- **Mesa / GLAD (`switch-mesa`, `switch-glad`)** — OpenGL ES 3.2 graphics backend
- Other third-party components located in `third_party/`
